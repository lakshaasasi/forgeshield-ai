
# 🛡️ ForgeShield AI — Document Forgery Detection

A web application that detects forged documents using AI, image processing, and OCR.
Built for **NIT Hackathon**.

## 🚀 Features
- 📄 Upload PDF or image documents
- 🔍 Detects tampering and forgery using OpenCV
- 🔤 Extracts text using OCR (Pytesseract)
- 🌐 Multi-language support via LangDetect
- 💻 Clean web interface built with Flask

## 🛠️ Tech Stack
| Technology | Purpose |
|---|---|
| Flask | Web Framework |
| OpenCV | Image Processing |
| Pytesseract | OCR Text Extraction |
| PyMuPDF | PDF Processing |
| LangDetect | Language Detection |
| Pillow | Image Handling |

## ⚙️ Installation
```bash
pip install -r requirements.txt
python app.py
```

## 📸 How It Works
1. Upload a document (PDF or image)
2. ForgeShield AI analyzes it
3. Get instant forgery detection results
